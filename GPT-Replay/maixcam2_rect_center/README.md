# MaixCAM2 低开销黑框视觉与激光偏差

备份应用构建号：`2026-11-10-fast-perspective-v1`，应用版本 `1.4.0`。在 MaixVision 中打开本目录并选择“运行项目”；入口、配置和 `vision/` 要一起下发。

## 检测流程

| 阶段 | 做法 |
|---|---|
| 新目标/失锁 | 原图按宽度缩至 320 px，只执行一次 Otsu；失败时再执行一次局部自适应阈值。没有固定阈值列表扫描，也没有全图 Hough 组合 |
| 快速提案 | 暗色闭运算、轮廓面积和包围框先筛，再对少量最大轮廓做多边形逼近。黑环外沿因反光与背景连通时，也从互补亮色掩膜提出靶纸内沿 |
| 几何验证 | 四边凸性、边长/面积下限；平面投影把黑带采样点映射回当前原图，验证胶带宽度、暗带及内侧亮纸证据。细屏幕边框、实心黑块因缺少宽暗带/内侧亮面而拒绝 |
| 原图精修 | 在候选四边窄带采集当前帧灰度跃变，用 `fitLine` 拟合四边，求相邻线交点。没有当前帧的可靠证据时丢弃结果，不沿用旧中心 |
| 稳态跟踪 | 优先在上一帧框附近检查当前帧；失败后搜索扩展 ROI；仍未命中才扫缩小后的全图 |
| 中心解算 | 四角保留轮廓环序，不固定图像左上角顺序。矩形对角线交点在平面透视下仍是中心；四边黑带的物理模型处理两种旋转对应关系 |

内沿与外沿提案使用循环角点序，不用 `x+y` 强行指定左上角。正视物理矩形两种边方向都参与检验，所以靶纸可在画面中横放、竖放或连续旋转；当前单应模型只针对靶纸平面，不是通用镜头畸变校正。

算法处理平面靶纸的任意面内旋转和透视梯形变形。镜头径向畸变需要镜头标定；本备份默认关闭未经标定的 `lens_corr`，避免额外整图计算和错误校正。

## 性能与边界

- 失锁每次全图最多两种低分辨率二值化提案：Otsu 一次，自适应阈值一次。
- 稳态跟踪不扫阈值、不遍历全图轮廓、不运行 Canny/Hough。
- 失锁当帧最多查 ROI 和全图各一次；找不到时返回无效，不保留旧目标。
- 自适应阈值和反光仍受曝光、胶带完整度及暗背景连通影响；拒识优于误锁。
- 合成测试覆盖不了全部实机反光、运动模糊和遮挡；需要在 MaixCAM2 上按真实距离验收。

## 激光偏差

默认 `LASER_MODE="detect"`，在固定参考点附近做小 ROI 亮斑检测。只有光点和靶框都有效才画从激光到靶心的箭头，计算 `dx=target_u-laser_u`、`dy=target_v-laser_v`。丢失时偏差无效，不沿用上一帧光点。`LASER_PIXEL` 是截图搜索初值，不是光学标定值。

默认 `ENABLE_UART=False`。启用 `UART_PROTOCOL="aim"` 后发送：

```text
@A,aim_valid,tx,ty,lx,ly,dx,dy,calibrated,laser_valid,target_valid%\r\n
```

下游必须检查 `aim_valid`；本应用只测量、显示和可选发送坐标，不驱动电机。

## 配置

| 参数 | 默认 | 作用 |
|---|---:|---|
| `CAMERA_W/H` | 640/480 | 灰度相机分辨率 |
| `LENS_CORR` | False | 只有使用对应镜头标定时才启用 |
| `SEARCH_WIDTH` | 320 | 失锁搜索缩小宽度；小目标可加大 |
| `ADAPTIVE_BLOCK_SIZE/C` | 31/8 | Otsu 无提案时的局部阈值 |
| `MAX_CANDIDATES` | 8 | 每次扫描最多验证的大轮廓数 |
| `BLACK_FRAME_MM` | 18 | 胶带物理宽度，须与实物相符 |
| `LASER_MODE` | detect | 实测光斑；fixed 为显式固定坐标模式 |
| `SHOW_FPS/SHOW_WIDTH` | 15/480 | 预览限频/画布宽度，不跳过检测帧 |

性能测试包含 24 个随机透视场景、0°～345°每 15° 一例、同一目标连续旋转 24 帧、突发平移、320×240、黑白/纹理负样本、上电空场与失锁重捕。最近一次运行结果：48/48 静态旋转/透视场景检出，24/24 连续旋转帧检出，最大中心误差 0.74 px；320×240 共 12/12 通过；6 个负样本零误检；PC 稳态 P95 约 1.48 ms，空场 P95 约 0.59 ms，冷搜索 P95 约 3.89 ms。耗时随 PC 负载波动，绝对值不是 MaixCAM2 FPS；板端以 `[perf] detect/loop/FPS` 为准。
