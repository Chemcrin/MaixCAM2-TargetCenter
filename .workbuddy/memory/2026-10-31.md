# 2026-11-01 · C2 失败分类（v1.1.3）

- `stage='no_black_frame'` 语义保持不变（tests/target_api 都依赖），失败帧**新增**两个只读字段：
  `fail_stage`（本帧走过的层级，如 `track+full`、`full`、`track+roi+full`）与
  `fail_reason`（**首次**失败原因：`track_refine` / `track_verify` / `roi_no_proposal` /

  标注视频的 "NO LOCK" 也带上这对码；`diagnose_video` 先打内置归因再打尸检。

  `rejected` 33；与尸检脚本结论一致。这两个数字对应**完全相反**的改法（精修内点/残差 vs 暗带证据），
  下一轮调参前必须先看板端分布。
