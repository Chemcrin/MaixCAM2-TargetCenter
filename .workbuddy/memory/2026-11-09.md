## 视觉引擎第二次重写：降到 3.5ms/帧、42fps（fast-track-v8/v9）

用户三个诉求：晃动就丢锁、帧率个位数、逻辑不够优。定位后确认根因不是参数，
是"每帧在 640x480 全图上做边缘+轮廓+逐边采样"，而板上每次 Python 级 numpy
调用约 1ms —— **调用次数就是耗时**。

**新链路（五段，全部只调十来次 cv2/numpy）**
1. 降采样 1/2（INTER_AREA）；
2. 阈值 = 0.62 × 画面 90 分位亮度（分位数在 1/16 子采样上算），
   夹在 [max(45, p2+15), 160]；
3. `connectedComponentsWithStats` 一次拿全部块（不用 findContours 逐轮廓取外接框）；
4. 四道门挑环：面积 / 长短边比 1.05~2.6 / 填充率 0.03~0.70 /
   **四条边最弱一条的暗像素占比 ≥ 0.20**（这一条把"框住靶心的稀疏暗结构"排掉：
   环实测 0.27~0.45，窗棂/柜门缝只有 0.10）；
5. 定心：框心向外扫四条线找"亮→暗"跨越，取左右/上下弦中点。外接框中心会被
   阴影带偏（实测 bbox 心 7.7/5.9px vs 弦中点 3.8/2.3px），弦中点不需要任何
   单应或拟合。

**稳定性三件套（"晃动丢锁"的解药）**
- ROI 跟踪：锁定后只在上帧框的 1.35 倍范围内找，按速度外推；
- 抖动容错：抓不到就按速度外推继续输出最多 6 帧（RECT_HOLD_FRAMES），
  超过才 HOLD + 全图重搜；
- 跟踪门 0.45×框边长 + 速度限幅 2500px/s + dt≥4ms 才更新速度。最后这条是必须的：
  连拍两帧 dt≈0.2ms，速度除出天文数字，ROI 被甩飞，实测会锁到墙上别的东西。

**踩过的三个真 bug（都写进注释了）**
1. ROI 原点是原图坐标，却又乘了一次缩放系数 → 中心系统性偏一个 ROI 原点；
2. 尺寸容差按"上一帧"比 → 每帧可缩 45%，一路缩到纸面圆环上
   （250x180 → 114x112 → 50x52）；改成按"锁定尺寸"比，参考尺寸每帧最多跟随 2%；
3. stats["components"] 在 _detect 里被 _last_components(0) 覆盖 → 失败归因
   永远报 no_proposal。

**板端实测（v9，MaixVision 运行当前文件）**
- detect_fps = 38.8~42.6（原 2.9），capture = 59.6，det_ms = 8.8~34.3（原 337），
  det_path=track，det_split = 8.4~33.9；
- 60 秒内 30 次采样全部 valid=True stage=plane_frame，drop(show)=0；
- [aim] 的 dx 从 86 收敛到 -55（闭环在动，但会过冲，属云台增益/标定问题）；
- 帧率波动原因：跟踪 ROI 变大时连通域变贵（3ms→34ms）；已改成按 ROI 尺寸自适应
  降采样档位，把每帧像素量钉在 RECT_TRACK_MAX_SIDE=240。

## 视觉引擎第四次重写：环-洞结构 + 四线交角（quad-track-v10→v15，app 1.7.0）

**用户诉求**：稳定、高帧率、全角度（大斜角梯形）、透视畸变下中心精确、逻辑可复述。
**方案**：黑胶带环 = 一块暗带围出一个亮洞；洞轮廓 = 纸边矩形；四条边各拟一条直线
（闭式最小二乘，tolist 后纯 Python）、四线求交得四角、对角线交点 = 靶心（透视几何
精确解）。复用 v9 的 ROI 跟踪骨架（速度外推、续命 6 帧、尺寸基准锁定、自适应降采样）。
删除 Canny/逐边剖面精修/单应全链。

**真机调试抓出的五个坑（全是板上/真实场景才有的）**：
1. real_board_frame 固件里胶带灰度 118 > 全局分位阈值 116——环碎成片围不出洞。
   **量测阈值改为候选裁剪图内 Otsu**（暗带|亮面双峰天然分离），不做全局假设。
2. 显示器场景（v113 录像）：边框 35 与暗墙 75 都低于阈值连成 mega-blob，
   bbox≈整幅——面积上限门任何 <1 的值都杀真候选（置 1.01 实效关闭）；
   「洞≥0.15×blob bbox」门在污染 blob 上必挂，换成**洞周暗带封闭性**
   （洞外 0.06×短边一圈暗占比 ≥RECT_BAND_COVER，膨胀裁剪到洞邻域省 3 倍）。
3. 柜门/墙缝的不规则亮洞：拟线残差爆表 + minAreaRect 填充率低——
   加**规整性门**（平均残差 ≤0.03×短边、凸性、回退路径也要过填充率 ≥0.55）。
4. 靶纸放低+后仰后洞长边 ~115 < 原下限 120 被杀——RECT_HOLE_MIN_PX 120→70；
   且它在候选榜只排第 3（暗门/暗墙 bbox 更大）——RECT_MAX_CANDIDATES 2→4。
5. ring_hole 不能只看最大顶层轮廓：Otsu 后环自己是第 2 大顶层（mega-blob 最大
   子洞是 424x543 的亮墙面被尺寸门正确拒掉）——改为**按周长粗排前 8 个顶层、
   每个试周长前 5 的子洞**（周长代理会被破碎缝虚高骗，只看 1 个会漏真洞）；
   候选取**打分制**：score = 洞内对比度 − 40×|边比−模型比1.5|，全场最优，
   治了柜门边比 2.7 擦线误锁。
