- 现场照片（手机拍屏）：靶纸=白纸+同心圆，**四周没贴黑胶带**；算法反锁画面上方
  被暗边围住的亮墙，中心 (244,28)、area≈6万、aspect≈1.3、dy=-175。
  根因：反色二值化找的是"闭合暗环"，没胶带→靶纸不进候选；而墙/柜门/门框这类
  "暗边围出的横放矩形"全部过三层，`select_largest` 取面积最大就锁错。
- 改法：`algo.find_concentric` 独立成链（不属第四层判据，不改三层），
  `logic` 里**同心圆优先、四边形兜底**；`RECT_CIRCLE_ENABLE=False` 可完全退回旧行为。
  绘制层 `draw_result` 支持 `circle` 字段（绿圈+十字），失败文案改 `NO TARGET`。
- **实测关键数据**（改参数的依据，别凭感觉调）：
  - `RECT_CIRCLE_CLOSE_KERNEL`：3 **会破坏检测**（同心圆全灭），5/7 正常 → 定 5。
  - `RECT_CIRCLE_MIN_RINGS` 必须是 2：真机帧只有最外圈+一圈内环闭合（圆度 0.889/0.897）。
  - `RECT_CIRCLE_MIN_RADIUS` 必须小（2.0）：靶纸最内圈半径实测只有 2.7px。
  - 圆度阈值 0.80：正方形只有 0.785，再低就会被矩形钻进来；0.86 会把真靶纸拒掉。
- 结果：`real_scene_corner_gap.png` 从误锁 (297.5,65.5) → 正确回 (246.2,161.2)，
  stage=concentric，1.3ms；合成圆靶中心误差 0；单圆/正方形/空白/散点噪声均不误报。

## 夜：Canny+单应+72点采样的重构方案（只做方案，未改代码）
用户提案：Canny → 多边形逼近四角 → 沿边内外灰度差分类内外框 → 8×8 高斯消元解 H →
1px=1mm 正视化 → 72 等分采样标准圆 → 逐点逆变换回原图。要求"说人话"的方案，允许推翻重写。

**实测结论（PC，`D:/Python311/python.exe`，改参数前先看这几条）**
- **Canny 边图做不出四角**：`real_board_frame` / `real_scene_corner_gap` 两帧，eps 0.01/0.02/
  0.03/0.05/0.08 五档，Canny(+dilate) 轮廓 **0 个四点近似**；自适应二值最多 3 个（eps 3%）。
  根因：胶带内角是圆的 + 边被灰块/高光切断，最大轮廓近似后是 8/10/6 点。`len!=4` 直接丢候选。
- **谐波拟合只能"修"不能"找"**：从真圆心偏 8px 起跑，残差 0.03px 却是错心（小窗口里总能
  找到暗像素，3 参数永远拟合得上）。⇒ **残差/置信度不能用中心相关量**，必须用与中心无关的
  证据（环条数、环间距等距性、对比度、两框自洽残差）。
- **全局径向锐度搜索有效**：目标 = 72 射线高通径向剖面的最小值（越尖越好），±8px 网格唯一
  收敛到 `real_board_frame` 的 (213,186)，6 倍放大目视核对正好在环心（图
  `reports/zoom_center_check.png`，红叉=框心 (205,180)，绿点=搜索值）。
- **环签名（真心处）**：r = 12.0 / 24.2 / 37.0 / 49.5 px，间距 12.0–12.8（**CV≈3%**），
  对比度 13–28 灰阶。等距是强判据：墙/柜门/门框没有等距同心环。
- 当前基线复跑：`real_board_frame` → all_filtered；`real_scene_corner_gap` → concentric
  (246.2,161.2)；两张 negative 正常拒检。

**方案定案（五段）**：① 半分辨率出候选 → ② 沿边取点/拟直线/求交定亚像素四角（不对边线做
approxPolyDP）→ ③ 归一化 8×8 高斯消元解 H（有内框则 8 点超定，残差当"两框自洽"证据）→
④ 72 射线×多半径 → 高通 → 找环 → 一次谐波解偏心 (a,b) → ⑤ 判据表判决。
**核心口径变化：黑框从"答案"降级为"坐标系"，靶心由环量出**；正视面只是坐标系，不生成 warp 图像
（点采样比整幅 warp 便宜两个数量级且精度更高）。
判据表：带+环→高；带无环→仅两框自洽时接受（框心）；无带+环→中；都无→HOLD。

**待用户拍板**：① 靶纸真实尺寸（胶带是内缩的，不能填 210×297）；② 现场是否必贴胶带
（决定能否要求双证据齐全）；③ 重构期是否保留 `RECT_ENGINE` 旧链路开关。
**第一轮硬门禁**：先在板上量 blur/resize/Canny/findContours/5000 点双线性/8×8 六个原语耗时
（v1.2 实测 105.6ms、PC 仅 1.4–2.2ms，差 50 倍，不能靠系数猜）。

**实现要点 / 踩过的坑**

  挡掉遮挡物（灰斑 146 vs 胶带 50）。
- ⚠ 外法线方向极易搞反：窗口必须 `+span(框外) → -inward(框内)`，反了会去扫阴影，
  实测表现为"内点跑到外点外面、带宽只有 5px"。
- ⚠ 只取"第一个上升沿"当纸边会被带内噪声/遮挡边界带跑（出现带宽 0.2px 的假点）。
