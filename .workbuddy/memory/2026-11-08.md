# 2026-11-08

## 黑框识别回到“只认框”：去掉环、去掉同心圆兜底（v1.4.0）
用户定调（原话要点）：**只要 Canny-多边形逼近-候选-找矩形**；实际场景里环几乎不可见，
是干扰项；环的定位后面用固定云台角度解决，**不要在黑框识别里加环**。

**改动**
- 候选来源：自适应反色二值化 → **Canny（可自动阈值）+ 闭运算**。双阈值 `RECT_CANNY_LOW/HIGH`
  就是“过滤纸面图案”的旋钮（0/0 = 按中位数自动），闭运算核 `RECT_EDGE_CLOSE`。
- 删除：`sample_polar` / `ring_report` / `_ring_check` / 环相关 config / `_legacy` 旧链路 /
  `find_concentric` 兜底 / `find_quad_candidates` / `select_largest` / `success_circle_result` /
  smoke 用例 6、7。
- 保留：内外框精修（内框定心）、归一化 8×8 单应（只用于 `rect_to_image` 读数，不参与判决）。
- 版本：`app.yaml` **1.4.0**（之前漏改，用户看不出新旧）；`BUILD_ID=2026-11-08-plane-frame-v2`；
  屏幕右上角打 `v<slug>` 短标识，左上角失败时显示 `NO TARGET <原因>`。

**实测 / 踩坑**
- ⚠ **Canny 轮廓是细线，`cv2.contourArea` ≈ 0**，面积门会全灭 → 面积改用
  `minAreaRect` 的 w*h。这是本轮最大的一处坑。
- ⚠ 纯 Canny 轮廓是“回”字形（内外两圈=8 个角），`approxPolyDP` 永远给 8 点；
  `real_board_frame` 被遮一角时给 5~6 点。→ “找矩形”必须用最小外接矩形，逼近只作候选。
- 结果：`real_board_frame` (212.91,186.56)、`real_scene_corner_gap` (245.84,161.36)，
  距印刷中心 0.3~0.5px；`negative_e880` 拒检。
- **`negative_e421`（笔记本屏幕）会误检**——去掉环之后没有“是不是靶纸”的判据，
  与 v1.3.0 同一水平，属已接受边界（README §4 已写明）。
- 试过两个“无环”替代判据，都不可用：带宽比 0.18 vs 0.073 的差距来自**阴影**，
  无阴影时真靶纸会掉到 0.095 被误拒；纸面纹理方向反了（印刷环本身就是强边缘）。
- 门禁：check_pc 4/4，smoke 5 组全过。
