# 2026-10-21 · v1.0.1 四类现场问题压力复测

> 目标：验证 2026-10-19 的 v1.0.1（A+B）是否解决用户列的四个问题：
> ① 抖动/轻度拉长变形时识别丢失；② 复杂环境识别能力一般；③ 丢失后附近难复锁；
> ④ 云台移动时容易丢失。**未上板**（192.168.2.16 ping 不通），以下均为 PC 合成/真机帧压力测试。

## 方法（临时 harness，未进库）

- 合成靶：`test_performance.scene` 的 A4 黑框，解析真值中心。
- 抖动/变形：±1° 旋转、1.2% 各向异性缩放、±2.5px 平移、每角 ±3.5px 透视扰动、噪声 σ=3。
- 真机帧：`real_board_frame.png` / `real_scene_corner_gap.png` 做同样的仿射抖动。
- 云台运动：目标 24/60 px/帧往返，运动模糊核 9/21px；`ENABLE_MOTION_PREDICT` 开/关对照。
- 复锁：连续 5 帧空白后，目标平移 25/50/80/120px（合成）或 30/60/100px（真机帧）。
- 复杂环境：目标贴到 `negative_e421/e880` 真实照片背景；随机 20/40 个暗块+文字；
  低对比（paper150/tape90/bg140）+ 干扰；无目标的纯干扰帧统计误检。
- 遮挡：目标顶边/右边/角/中心分别盖灰块。

## 逐条判定

1. **抖动/轻度拉长变形**：**部分解决**。A+B 把真机帧从 0/40 提到 40/40、36/40；
   但 corner 仍有 4/40 丢帧，且透视变形下中心误差从 0.85px 回退到 2.10px。
   根因：删掉共线硬门限后，混入的内沿/印刷圆/阴影点会参与 fitLine；需要稳健线拟合。
2. **复杂环境识别能力**：**未解决/需实测**。清晰目标贴真实照片 8/8 能检出且中心准；
   但纯干扰帧 17/20、14/20 被误判为有效，说明 `_verify` 只验“四边暗带”，
   不验内框比例/胶带厚度/内部结构；复杂环境可能锁到窗框、桌沿、海报边。
3. **附近复锁**：**基本解决（≤60px）**。合成 25~120px、真机 board 30/60/100、corner 30/60 均 1 帧；
   corner 100px 仍失败（单帧 fresh 也失败，说明是检测而非状态问题）。
4. **云台移动**：**未解决**。无模糊时 valid 30/30，但 60px/帧只有 21/30 track；
   加 9/21px 运动模糊后 track 19/20，中心误差 2.7/7.9px。板端全图搜索 0.5~1.4s，
   回退一帧就可能 stale → 闭环 HOLD。

## 下一轮方案（按优先级）

### P0 变形下的中心精度（先修回归）

- `_refine` 的 fitLine 改为 **RANSAC/加权内点拟合**：每条边先找最大直线共识集（≥5 点），
  只用内点拟合；共线点不足时回退输入边，不再用全点 Huber 被 >50% 离群点拉偏。
- band-run 只做**多峰择优**，不做硬门限（2026-10-21 原型已证明硬门限会把 board 框缩 10px、中心偏 4.6px）。
- 用候选四边形边做先验：精修位移 >3px 且证据不足时保留输入边。
- 验收：`perspective_deform` max ≤1.0px（当前 2.10），抖动 max ≤1.5px（当前 2.28）；
  `test_real_scene` 6/6、`verify_subpixel` 121/121 不回归。

### P1 复杂环境误检

- 恢复/实现当前**死参数** `MIN_INNER_RATIO` / `MAX_INNER_RATIO` / `DARK_CENTER_MIN` /
  `MIN_ANGLE_DEG`：内框/外框面积比、胶带厚度（mm 单应）、内部亮度均匀性、角点角度。
- 加“胶带厚度一致性”检查：四条边暗带宽度经 homography 反算到 mm，应接近 `BLACK_FRAME_MM`。
- 全图搜索新锁定可加 **2 帧确认**（仅 search 路径，track 不确认），挡住瞬态窗框/桌沿；
  `detect_black_frame` 单帧 API 保留原语义。
- 新增负样本：随机暗块/文字/窗格纯干扰 20 帧，要求 **0 误检**；
  目标贴真实照片 8/8 保持；目标+40 干扰/低对比保持 12/12。
- 验收：纯干扰 0/20；complex 目标 ≥11/12；`negative_e421/e880`、U 形、window_grid 仍拒。

### P2 复锁与全图搜索延迟

- `_roi_retry` 单次 → 保留最近 2~3 个四边形做**多 ROI**；`ROI_PADDING` 0.20→0.35。
- `_search` 的 `SEARCH_MAX_CONTOURS=16` 在复杂场景可能把目标挤出前 16；
  改为按“面积 + 长宽比 + 边缘暗带预筛”排序，或分两轮：先 ROI/中心区域，再全图。
- `_finalize` 首轮精修失败回退粗候选（v0.8.0 行为）；`refitted=3` + 输入边回退。
- 板端目标：搜索态 0.5~1.4s 压到 <0.2s（至少让 `RESULT_MAX_AGE_S` 不再必 stale）。
- 验收：真机 corner 100px 复锁 ≤2 帧；board/corner 30/60px 1 帧；全图搜索单帧完成。

### P3 云台运动/运动模糊

- `PREDICT_MAX_PX` 60→120（云台快速段），`TRACK_RADIUS` 12→16/20；
  两级 refine：先 12px，失败再 24px（仅 track 路径）。
- 预测假设从 2 个增到 3~4 个：上一帧位置、预测位置、零速度、反向；方向反转时不再整帧丢。
- 运动模糊：在 `_refine` 用 Gaussian 导数/多尺度梯度，或先轻度 deblur；
  线模型跨帧加权（上一帧直线做先验）。
- 若 IMU 可用，评估 `ENABLE_IMU_FEEDFORWARD`（当前 False）用云台运动预测目标位移；
  同时削 draw 20~40ms，避免 `det_ms` 被主线程拖慢。
- 验收：60px/帧 + 21px 模糊 track ≥28/30，中心误差 ≤2px；板端 `det_stage` 在云台运动中保持 `track`。
