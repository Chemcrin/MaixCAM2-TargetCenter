## 一、项目一句话

2025 全国大学生电子设计竞赛本科组 **E 题《简易自行瞄准装置》** 的视觉模块。

- **靶心定义**：A4 靶纸四周 1.8cm 黑胶带矩形的**两条对角线交点**（射影不变量）。
  物理靶心是 ≤0.1cm 的红点，在 165cm 处仅约 0.67px、物理不可见，**只能由黑框几何反算**。
- **输出**：靶心像素坐标 `(u, v)`（A 轨另给局部尺度 `px_per_cm`），经串口交给云台主控解算激光指向。
- **运行平台**：MaixCAM2（MaixPy v4 / MaixCDK，Ubuntu），屏幕 640×480。
- **工程形态**：`main.py` + `app.yaml` + `config.py` + `vision/`，另生成单文件版 `dist/main_single.py`。

## 三、已做的优化（按主题归档）

### 1. 性能治理（A 轨为主）

- `findContours` 代价 ∝ 轮廓数（2 万条 ≈190ms）→ `boundary_estimate()` 预筛 + ROI 跟踪 + 掩膜预算。
- 帧率从 0.1fps 提升到可用；**锁定后只扫 1 个掩膜**（稳态个位数，锁定=1）。
- 缩小图粗定位失败才回退全分辨率。

### 2. 抗抖跟踪（A 轨，`tracker.py`）

- 常数速度卡尔曼 + 自适应过程噪声 + 新息门限 + 尺寸/清晰度一致性校验。
- 关键结论：抖动位移是**必须跟踪的真实运动**，不能用更重的低通「滤掉」（已实测证伪）。

### 3. 显示链路与帧率（B 轨，最大的一块工程债）

| 版本 | 改动 | 效果 |
|---|---|---|
| v0.4.3 | 显示移出主循环（主进程内显示线程 `SHOW_ASYNC=True`），画布池丢帧不排队 | 修「只有 1.5 帧」 |
| v0.4.4 | `show()` 计时探针 | 定位真凶 |
| **v0.4.5** | `DISABLE_MAIXVISION_STREAM=True`：建 Display 前置 `MAIXVISION=0`，从源码层掐断图传 | show 505ms → 1~5ms |
| v0.4.6 | 入口模块化，`main.py` 923 → 296 行 | 覆写损失面 -70% |

**根因（已抓 MaixCDK C 源码确证）**：MaixVision 图传 websocket 未连上时，
`send_image()` 会**忙等 500ms 并空转 CPU**；`Display::show()` 第一件事就是调用它。
显示线程化只把阻塞挪出主循环，未消除忙等；唯一出路是**建 Display 前让 `MAIXVISION≠1`**。

### 4. 搜索 / 重捕获调度（B 轨，10-12 焦点）

| 版本 | 改动 | 效果 |
|---|---|---|
| v0.5.1 | 恢复「单帧穷尽搜索」（v0.4.3 曾被改成每帧只轮换 1 阈值） | 重捕获 **11 帧 → 1 帧** |
| **v0.5.2** | 新增 `_motion_delta()` 运动预测：用上两帧四角逐角位移外推本帧位置，窄带精修；`SEARCH_SPLIT_FRAMES=False` 单帧跑完搜索 | track 命中 18px **0/10→9/10**、36px **0/5→4/5** |

**防弯路铁律**：不要靠加大 `TRACK_RADIUS` 治快移 —— 实测半径 80 时连 6px/帧都开始掉
（大步长会误锁印刷线或另一侧黑边）。必须用运动预测。

### 5. 云台与标定（B 轨）

- 修 v3 轴映射错误：`ttyS2`=yaw(ID=2)、`ttyS0`=pitch(ID=1)，`DIR_SIGN=-1/-1`。
- `ACC_DEFAULT 0→80`（0 = 瞬时启停 = 卡顿源）。
- `LENS_CORR True→False`（未标定的畸变校正会引入畸变）。
- 上电自检改为**屏幕右上角 `SELF-TEST` 按钮**触发，修「fault=False 被误判为故障」的真实 Bug。
- 控件放缓：GAIN 0.5→0.3、RPM 120/400→60/150、MAX_STEP 360→80，加输出低通 + 增长限速 + 运动完成等待。

### 6. 算法选型定论（避免重复调研）

- **不换算子**：纯 Canny 与现行「二值化主 + Canny 兜底」等价 → 29/30 对 29/30、0 误检。
  真正把中心压到 0.061px 的是 **`fitLine` 亚像素精修**，不是候选生成算子。
- **国一方案不可整体照搬**：忠实移植后仅 11/30（两处硬缺陷：绝对面积界是尺度标定、`_order_points` 极值法在 45° 退化）。
- **逆透视求中心**已成立，B 轨 `project_points(mm→px, (w/2,h/2))` 数学等价于对角线交点。
