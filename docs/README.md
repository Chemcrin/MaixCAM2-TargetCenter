# 文档导航

本仓库文档的地图。每份文档只回答"管什么、什么时候读"；
具体数值与当前状态以代码为准（文档给符号名），历史沿革以 git 为准（文档不记流水）。

## 文档总览

| 位置 | 文档 | 管什么 | 什么时候读 |
|---|---|---|---|
| `AGENTS.md`（仓库根） | 协作契约 | 工作边界、门禁命令、git 规范、完成定义 | 动手改任何东西之前 |
| `maixcam2_rect_center/README.md` | 应用说明 | 识别与云台瞄准的架构：模块职责、数据流、关键机制 | 理解或修改算法与链路时 |
| `docs/ZDT电机资料/README.md` | 硬件资料索引 | ZDT Emm42_V5.0 官方说明书（同目录 PDF）的页码索引、与 `stepper_link.py` 的功能码对照、驱动器必改设置 | 接线、改驱动器参数、加回零或读状态命令时 |
| `存档/项目自检/硬件标定与上板检查.md` | 运维参考 | 标定门槛与上板操作步骤 | 首次上板、重新标定时 |
| `存档/项目自检/板端识别问题整理_2026-10-13.md` | 运维参考 | 板端识别类问题的定位思路与实锤案例 | 板端识别异常时 |
| `存档/项目自检/板端故障排查_2026-10-18.md` | 运维参考 | 板端云台/帧率类故障的定位与修复记录 | 云台不动、帧率塌时 |
| `存档/分析文档/视觉识别问题分析_2026-10-31.md` | 分析快照 | 实拍录像上的识别有效率、失败归因、代码逻辑冲突清单与已修项 | 调识别判据、问"为什么锁不上"时 |
| `.workbuddy/memory/` | 工作日志 | 逐日流水与跨会话结论（`MEMORY.md`） | 追溯"为什么这么做"时 |

## 目录说明

```
25Efork/
├── AGENTS.md                  唯一协作契约（仓库根）
├── docs/                      文档导航（本文件）；新增现行文档放这里
│   └── ZDT电机资料/           云台步进驱动器官方手册 PDF + 页码索引
├── maixcam2_rect_center/      唯一可烧录应用；目录内只有 README.md 一篇文档
├── reports/                   工具产物（应用目录之外，不进库）：标注视频 / 逐帧 json / 报告
├── 存档/                      历史资料（只读）
│   ├── 项目自检/              现行运维参考（上板/标定/排查三篇，仍随现场维护）
│   ├── 分析文档/              阶段性审查、复盘、版本记录归档
│   ├── 提示词/  历史脚本/  历史快照/  reference/
└── .workbuddy/memory/         工作日志与跨会话结论
```

## 约定

- 文档描述架构与规则；数值、行号、当前版本一律不写进文档——拿文档里的符号名去代码里找。
- 变更记录不写进文档——git 历史即变更记录，文档只忠实于现状。
- 新增文档先判断"现行还是历史"：现行 → `docs/`；历史 → `存档/` 对应子类
  （存量三篇运维文档暂留 `存档/项目自检/`，迁移时同步更新引用）。
- 应用目录除 `README.md` 外不放任何文档（`app.yaml` 已把 `*.md` 排除出应用包）。
