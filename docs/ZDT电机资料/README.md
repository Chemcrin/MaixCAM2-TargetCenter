## 与代码的对应关系

`maixcam2_rect_center/vision/stepper_link.py` 实现的帧与手册完全一致，
字段顺序见手册第 36–38 页：

| 代码函数 | 功能码 | 手册位置 |
|---|---|---|
| `cmd_enable` | `F3 AB <使能> <同步>` | p.36 |
| `cmd_speed` | `F6 <方向> <速度2B> <acc> <同步>` | p.36 |
| `cmd_position` | `FD <方向> <速度2B> <acc> <脉冲4B> <绝对/相对> <同步>` | p.37 |
| `cmd_stop_now` | `FE 98 <同步>` | p.37 |
| `cmd_sync_motion` | `FF 66` | p.38 |
| `cmd_read` | `1F/20/21/24/27/30–3A` | p.41–44 |

轴地址与串口落在 `config.py`（`ADDR_YAW` / `ADDR_PITCH`、`YAW_DEV` / `PITCH_DEV`），
轴映射定案见 `AGENTS.md` §2。

## 上板前必须核对的三项驱动器设置

手册 p.19–22 有逐项说明，出厂默认值与本项目要求不同：

1. `P_Serial` → `UART_FUN`：出厂为 `RxTx_OFF`，不改则串口静默无响应。
2. `UartBaud` → `115200`、`Checksum` → `0x6B`、`Response` → `Receive`：与 `config.py` 一致。
3. `ID_Addr` → 两轴分别 1 / 2（地址跟着电机走，不跟端口）。

## 上位机

官方上位机（Windows，串口参数读写/曲线调试）**未随本目录提供**：官方仅通过语雀知识库
与 CSDN 文章附件分发，当前无可直接下载的公开直链。需要时：

- 官方资料库：语雀 `zhangdatouzhikong`（`ZDT_Emm42_V5.0 Modbus-RTU指令说明` 等同源）；
- 或直接用 OLED 按键改参数（p.18–23），本项目这三项设置都能在菜单内完成，不必依赖上位机；
- 第三方开源上位机可作替代：GitHub `BG4QBC/MyEmmControl`（C#，源码）。
