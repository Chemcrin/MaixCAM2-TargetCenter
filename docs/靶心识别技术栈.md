# 靶心识别技术栈（MaixCAM2 / MaixPy v4）

> 范围：**只讲"从一帧图像到靶心像素坐标"这一条链路**的技术栈与算法。
> 不涉及云台、电机、串口协议、扫描、时序控制。
> 所有 API 签名均按 MaixPy v4 官方 API 文档核对过，可直接照写代码。

---

## 一、目标定义

| 项 | 内容 |
|---|---|
| **输入** | MaixCAM2 一帧彩色图像（靶纸：A4 紫外感光纸，四周用 1.8cm 宽黑胶带描边；中心红点靶心 ≤0.1cm；同心红圆半径 2/4/6/8/10cm、线宽 ≤0.1cm） |
| **输出** | 靶心像素坐标 `(u, v)`；靶面尺度 `px_per_cm`；有效性标志 `valid` |
| **工作距离** | 约 50 ~ 165 cm |
| **精度要求** | 对应题目 D₁ ≤ 2cm 满分 → 视觉定位重复性目标 **σ < 0.5 px** |
| **时间要求** | 单帧处理 ≤ 10 ms（要留出余量给 2s / 4s / 20s 的各种时限） |

## 二、技术栈全景（自下而上五层）

```
┌─────────────────────────────────────────────────────────────┐
│ L5  时序层   One Euro Filter / 中值滤波 / 野点门控            │
├─────────────────────────────────────────────────────────────┤
│ L4  几何层   角点归一化 → 单应矩阵 H → 投影求靶心              │
│              NumPy + OpenCV (cv2.getPerspectiveTransform)     │
├─────────────────────────────────────────────────────────────┤
│ L3  检测层   find_rects（主）/ 黑阈值二值化 + find_blobs（兜底）│
│              binary / erode / dilate / open / close           │
├─────────────────────────────────────────────────────────────┤
│ L2  图像层   maix.image.Image   ←→   NumPy ndarray            │
│              image2cv / cv2image  ·  crop / resize / 格式转换  │
├─────────────────────────────────────────────────────────────┤
│ L1  采集层   maix.camera.Camera                               │
│              曝光/增益/白平衡锁定 · set_windowing · 多通道      │
├─────────────────────────────────────────────────────────────┤
│ L0  硬件层   MaixCAM2（AX630C: 2×A53@1.2GHz Ubuntu + E907）    │
│              AI ISP · 4-lane MIPI CSI · M12 镜头              │
└─────────────────────────────────────────────────────────────┘
```

### 各层职责与选型

| 层 | 技术 | 为什么用它 |
|---|---|---|
| **L0 硬件** | MaixCAM2 / AX630C | 带 AI ISP（暗光噪点少）；支持最高 4K，分辨率是本题的硬需求（见第四节）；Ubuntu 环境下可以直接 `pip install opencv-python` |
| **L1 采集** | `maix.camera.Camera` | 提供 `exp_mode/exposure/gain` 与 `awb_mode/set_wb_gain` 手动锁定——**这是阈值稳定的前提**；`set_windowing` 可换等效长焦 |
| **L2 图像** | `maix.image.Image` | MaixPy 原生图像对象，自带 `find_rects`/`find_blobs` 等 C++ 实现，速度远快于纯 Python |
| **L2 桥接** | `image.image2cv` / `image.cv2image` | MaixPy 没有单应矩阵求解、距离变换、连通域分析，必须借 OpenCV；这两个函数是桥梁 |
| **L3 检测** | `find_rects` | 基于**图像梯度**的四边形检测，**不依赖颜色阈值** → 对紫外感光纸上的大片深色痕迹天然免疫 |
| **L3 兜底** | `binary` + 形态学 + `find_blobs` | `find_rects` 在运动模糊/反光时会漏检，需要一条基于颜色阈值的备选路径 |
| **L4 几何** | `cv2.getPerspectiveTransform` + NumPy | 靶纸在图像中必然有透视畸变，只有单应变换能同时解决"倾斜"和"求尺度"两个问题 |
| **L5 时序** | One Euro Filter | 低延迟 + 强抑抖，专为交互式跟踪设计；比卡尔曼好调、比滑动平均延迟低 |

### 数值计算库

| 库 | 用途 | 来源 |
|---|---|---|
| **NumPy** | 角点数组运算、矩阵乘法、投影、局部尺度求导 | MaixPy 固件通常已内置 |
| **OpenCV (cv2)** | `getPerspectiveTransform`（单应）、`findHomography`、`distanceTransform`、`connectedComponentsWithStats`、`morphologyEx` | 需 `pip install opencv-python`（系统是 Ubuntu，可装） |

## 三、核心算法：从四个角点到靶心

### 3.1 关键前提：靶心不能靠"找红点"

题目规定靶心红点直径 **≤0.1cm**。在 165cm / 1280px 下靶面尺度约 **6.7 px/cm**，红点只有 **0.67 像素**——物理上不可见。红圆线宽 0.1cm 同理。

**唯一可行路线**：用黑色胶带描出的矩形做几何反算。

### 3.2 靶纸的物理定义

黑胶带 1.8cm 宽贴在 A4 纸四周边缘，所以视觉上有两圈边：
- **外沿** ≈ A4 轮廓 = **21.0cm × 29.7cm** ← 用这个
- 内沿 ≈ 17.4cm × 26.1cm

`find_rects` 返回哪一圈不确定，会导致尺度跳变。**对策**：取面积最大的候选（外沿），并做尺度跳变检测。

靶面坐标系（左上角为原点，x 向右，y 向下）：

```
(0,0) ──────────────────── (21.0, 0)
  │                            │
  │         · 靶心               │
  │      (10.5, 14.85)          │
  │                            │
(0,29.7) ──────────────── (21.0, 29.7)
```

### 3.3 步骤 ①：候选四边形检测

```python
rects = img.find_rects(roi=[], threshold=10000)
```

- **签名**：`find_rects(self, roi: list[int] = [], threshold: int = 10000) -> list[Rect]`
- **原理**：图像梯度 + 四边形拟合（与 AprilTag 的 quad detection 同源）
- `threshold` 越大越严格。靶纸对比度高，建议 8000~15000
- 返回的 `Rect` 提供：`r.corners()`（4 个角点）、`r.rect()`（外接框）、`r.magnitude()`（边缘强度，可作置信度）、`r.x()/y()/w()/h()`

### 3.4 步骤 ②：角点归一化排序（最容易出错的一步）

`corners()` 返回的 4 个点**顺序不保证**。不排序就会求出镜像/扭曲的单应矩阵，靶心直接跑到画面外。

```python
import numpy as np

def order_corners(pts):
    """排成 [左上, 右上, 右下, 左下]"""
    p = np.array(pts, dtype=np.float32).reshape(4, 2)
    s = p.sum(axis=1)             # x + y ：左上最小，右下最大
    d = p[:, 0] - p[:, 1]         # x − y ：右上最大，左下最小
    return np.array([p[np.argmin(s)], p[np.argmax(d)],
                     p[np.argmax(s)], p[np.argmin(d)]], dtype=np.float32)
```

**再补一道凸性/朝向校验**，剔除自交或退化的四边形：

```python
def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def is_convex(q):
    """图像坐标 y 轴向下，顺序正确时 4 个叉积应同号"""
    sg = [cross(q[i], q[(i+1) % 4], q[(i+2) % 4]) for i in range(4)]
    return all(v > 0 for v in sg) or all(v < 0 for v in sg)
```

### 3.5 步骤 ③：几何筛选

```python
A4_W_CM, A4_H_CM = 21.0, 29.7

def dist(a, b):
    return float(np.hypot(a[0]-b[0], a[1]-b[1]))

def quad_area(q):
    return abs(sum(cross(q[i], q[(i+1) % 4], q[(i+2) % 4]) for i in range(4))) / 2.0

def is_valid_quad(q, img):
    # 1) 面积下限：太小的四边形，角点精度不够
    if quad_area(q) < 0.01 * img.width() * img.height():
        return False
    # 2) 凸性
    if not is_convex(q):
        return False
    # 3) 对边长度比（透视下会变，给宽范围）
    w1, w2 = dist(q[0], q[1]), dist(q[3], q[2])
    h1, h2 = dist(q[1], q[2]), dist(q[0], q[3])
    for a, b in ((w1, w2), (h1, h2)):
        if min(a, b) < 1e-3 or max(a, b) / min(a, b) > 2.5:
            return False
    # 4) 长宽比（A4 = 1:1.414；透视会偏移，给 0.45~1.6 的宽容区间）
    ar = ((w1 + w2) / 2) / max(1e-3, (h1 + h2) / 2)
    return 0.45 <= ar <= 1.6
```

### 3.6 步骤 ④：单应矩阵（技术栈里最核心的一步）

```python
import cv2

def build_homography(quad_px):
    """输入排序后的 [TL, TR, BR, BL] 像素坐标 → 返回 3×3 单应矩阵 H（靶面 cm → 图像 px）"""
    src = np.float32([[0.0, 0.0], [A4_W_CM, 0.0],
                      [A4_W_CM, A4_H_CM], [0.0, A4_H_CM]])
    return cv2.getPerspectiveTransform(src, np.float32(quad_px))
```

**为什么必须用单应矩阵，而不是简单的"外接框中心"？**

| 方案 | 倾斜时 | 给出尺度 | 结论 |
|---|---|---|---|
| `blob` 外接框中心 | 中心偏移（透视） | ❌ | 不可用 |
| 对角连线交点 | 尚可（中心是仿射不变量） | ❌ | 可作交叉校验 |
| **单应矩阵 H** | ✅ 完全校正 | ✅ 局部求导可得 px/cm | **主方案** |

恰好 4 组对应点时，`getPerspectiveTransform` 比 `findHomography` 更快、结果更确定（不涉及 RANSAC）。

### 3.7 步骤 ⑤：投影求靶心

```python
def project(H, x_cm, y_cm):
    """靶面 cm 坐标 → 图像像素坐标"""
    v = H @ np.array([x_cm, y_cm, 1.0])
    if abs(v[2]) < 1e-9:
        return None
    return float(v[0] / v[2]), float(v[1] / v[2])

center_px = project(H, 10.5, 14.85)     # ← 靶心
```

**靶面关键点速查**：

| 点 | cm 坐标 |
|---|---|
| **靶心** | **(10.5, 14.85)** |
| A4 四角 | (0,0) (21,0) (21,29.7) (0,29.7) |
| 半径 r 的圆周点（角度 θ） | (10.5 + r·cosθ, 14.85 + r·sinθ) |

### 3.8 步骤 ⑥：局部尺度 px/cm

单应不是等距变换，尺度在整个靶面上是变化的，**必须局部求导**：

```python
def px_per_cm(H, x_cm=10.5, y_cm=14.85):
    p0 = project(H, x_cm, y_cm)
    px = project(H, x_cm + 1.0, y_cm)
    py = project(H, x_cm, y_cm + 1.0)
    if not (p0 and px and py):
        return 0.0
    return float((dist(p0, px) + dist(p0, py)) / 2.0)
```

这个值有两个用途：
1. 把像素误差换算成 cm，**直接预判题目里的 D₁ / D₂ 扣几分**
2. 交叉验证：用 A4 已知宽度 21cm 反查，检查 H 是否合理

### 3.9 兜底路径：黑阈值二值化 + `find_blobs`

`find_rects` 在运动模糊、反光、对比度下降时可能漏检。备选路径：

```python
TH_BLACK = [[0, 45, -25, 25, -25, 25]]      # L 低 + A/B 接近中性 = 黑

def detect_by_black_blob(img, roi=[]):
    tmp = img.copy()                 # ⚠️ binary 是原地操作，必须先 copy
    tmp.binary(TH_BLACK)             # 原地二值化：命中→白(255)，其余→黑(0)
    tmp.open(1)                      # 开运算：去除孤立噪点
    tmp.close(2)                     # 闭运算：把断开的框补上
    blobs = tmp.find_blobs([[80, 100, -128, 127, -128, 127]],   # 二值图里找白色
                           roi=roi, area_threshold=200,
                           pixels_threshold=200, merge=True, margin=8)
    if not blobs:
        return None
    b = max(blobs, key=lambda x: x.pixels())
    pts = b.mini_corners()           # ⚠️ 是 mini_corners()，不是 min_corners()
    if len(pts) != 4:
        return None
    return order_corners(pts)
```

**局限**：`mini_corners()` 返回最小面积矩形角点，只适合"靶纸基本正对相机、仅旋转"的情况；有透视时精度不如 `find_rects`。

### 3.10 步骤 ⑦：时序滤波（One Euro Filter）

角点在不同帧之间有 ±1~2px 抖动，经过 H 放大后靶心可能跳 ±3~5px。必须滤波。

```python
import math

class OneEuroFilter:
    def __init__(self, freq=30.0, min_cutoff=1.0, beta=0.007, d_cutoff=1.0):
        self.freq, self.min_cutoff, self.beta, self.d_cutoff = freq, min_cutoff, beta, d_cutoff
        self.x_prev, self.dx_prev, self.t_prev = None, 0.0, None

    @staticmethod
    def _alpha(cutoff, freq):
        tau = 1.0 / (2 * math.pi * cutoff)
        return 1.0 / (1.0 + tau * freq)

    def __call__(self, x, t):
        if self.t_prev is not None and t > self.t_prev:
            self.freq = 1.0 / max(1e-3, t - self.t_prev)
        if self.x_prev is None:
            self.x_prev, self.t_prev = x, t
            return x
        dx = (x - self.x_prev) * self.freq
        a_d = self._alpha(self.d_cutoff, self.freq)
        dx_hat = a_d * dx + (1 - a_d) * self.dx_prev
        cutoff = self.min_cutoff + self.beta * abs(dx_hat)   # 动得越快，滤波越弱
        a = self._alpha(cutoff, self.freq)
        x_hat = a * x + (1 - a) * self.x_prev
        self.x_prev, self.dx_prev, self.t_prev = x_hat, dx_hat, t
        return x_hat
```

**推荐参数**（靶心 u、v 各一个独立实例）：

| 场景 | min_cutoff | beta |
|---|---|---|
| 静态定位（要稳） | 0.6 | 0.004 |
| 动态跟踪（要快） | 2.5 | 0.02 |

## 四、为什么是这套技术栈（选型论证）

| 被排除的方案 | 排除理由 |
|---|---|
| **YOLO / CNN 目标检测** | 靶纸是强结构、已知尺寸、已知颜色的目标；传统 CV 延迟更低（无需模型加载，这对 2s 时限很关键）、可解释、易标定。MaixCAM2 的 3.2TOPS@INT8 留作极端光照下的兜底 |
| **找红色靶心/红圆** | 靶心 ≤0.1cm = 0.67px，物理不可见（见 3.1） |
| **`find_circles`（霍夫圆）** | 红圆线宽 0.1cm ≈ 0.67px，霍夫变换在这么细弱的边缘上极不稳定；且圆被黑框裁切 |
| **`find_blobs` 直接找矩形** | 对颜色阈值敏感；紫外感光纸上的大片深色痕迹会污染阈值；且只能给外接框，无法处理透视 |
| **模板匹配** | 靶纸在图像中的尺度变化范围极大（50cm 距离时占满画面，165cm 时只占 141px），模板匹配需要多尺度，成本高且不鲁棒 |
| **只用 OpenCV 不用 MaixPy 原生 API** | MaixPy 的 `find_rects` 是 C++ 实现且针对嵌入式优化，比在 A53 上跑 Python+OpenCV 快得多。**分工原则：像素级扫描用 MaixPy 原生，矩阵/几何运算用 OpenCV** |

**分辨率是隐性硬约束**：60° HFOV 下，165cm 处 A4 靶纸在 1280px 宽下只有 141px，靶面尺度 6.7 px/cm。若降到 640px，靶纸只剩 70px，角点定位精度会直接崩掉。**所以主通道必须 ≥1280 宽。**

### 6.3 两个必须记住的 API 陷阱

| 陷阱 | 说明 |
|---|---|
| **`binary` / `erode` / `dilate` / `open` / `close` 是原地操作** | `copy` 参数默认 `False`，会直接改掉原图。要保留原图必须先 `img.copy()` |
| **是 `mini_corners()` 不是 `min_corners()`** | MaixPy v4 的实际拼写是 `mini_corners()`，写成 `min_corners()` 会 AttributeError |

## 七、最小可运行 Demo（只做靶心识别）

保存为 `find_center.py`，用 MaixVision 运行即可。屏幕上会画出靶纸框、靶心十字和坐标。

```python
# find_center.py — 只做靶心识别，不含任何云台/控制逻辑
from maix import camera, display, image, app, time
import numpy as np
import cv2

# ===== 配置 =====
W, H = 1280, 720
A4_W_CM, A4_H_CM = 21.0, 29.7
CENTER_CM = (A4_W_CM / 2, A4_H_CM / 2)      # 靶心 (10.5, 14.85)

EXPOSURE, GAIN = 6000, 40                    # TODO 现场标定
WB_GAIN = [1.5, 1.0, 1.8]                    # TODO 现场标定

MIN_AREA_RATIO = 0.01

# ===== 几何工具 =====
def cross(o, a, b):
    return (a[0]-o[0])*(b[1]-o[1]) - (a[1]-o[1])*(b[0]-o[0])

def dist(a, b):
    return float(np.hypot(a[0]-b[0], a[1]-b[1]))

def order_corners(pts):
    p = np.array(pts, dtype=np.float32).reshape(4, 2)
    s = p.sum(axis=1); d = p[:, 0] - p[:, 1]
    return np.array([p[np.argmin(s)], p[np.argmax(d)],
                     p[np.argmax(s)], p[np.argmin(d)]], dtype=np.float32)

def is_convex(q):
    sg = [cross(q[i], q[(i+1) % 4], q[(i+2) % 4]) for i in range(4)]
    return all(v > 0 for v in sg) or all(v < 0 for v in sg)

def quad_area(q):
    return abs(sum(cross(q[i], q[(i+1) % 4], q[(i+2) % 4]) for i in range(4))) / 2.0

def is_valid_quad(q, img):
    if quad_area(q) < MIN_AREA_RATIO * img.width() * img.height():
        return False
    if not is_convex(q):
        return False
    w1, w2 = dist(q[0], q[1]), dist(q[3], q[2])
    h1, h2 = dist(q[1], q[2]), dist(q[0], q[3])
    for a, b in ((w1, w2), (h1, h2)):
        if min(a, b) < 1e-3 or max(a, b) / min(a, b) > 2.5:
            return False
    ar = ((w1 + w2) / 2) / max(1e-3, (h1 + h2) / 2)
    return 0.45 <= ar <= 1.6

def build_homography(quad_px):
    src = np.float32([[0, 0], [A4_W_CM, 0], [A4_W_CM, A4_H_CM], [0, A4_H_CM]])
    return cv2.getPerspectiveTransform(src, np.float32(quad_px))

def project(Hm, x_cm, y_cm):
    v = Hm @ np.array([x_cm, y_cm, 1.0])
    return None if abs(v[2]) < 1e-9 else (float(v[0]/v[2]), float(v[1]/v[2]))

def px_per_cm(Hm, x_cm, y_cm):
    p0 = project(Hm, x_cm, y_cm)
    px = project(Hm, x_cm + 1.0, y_cm)
    py = project(Hm, x_cm, y_cm + 1.0)
    return 0.0 if not (p0 and px and py) else float((dist(p0, px) + dist(p0, py)) / 2.0)

# ===== 检测 =====
def detect_target(img):
    """返回排序后的 4 角点，或 None"""
    best, best_area = None, 0.0
    for r in img.find_rects(roi=[], threshold=10000):
        cs = r.corners()
        if len(cs) != 4:
            continue
        q = order_corners(cs)
        if not is_valid_quad(q, img):
            continue
        a = quad_area(q)
        if a > best_area:                 # 取面积最大者（对应黑胶带外沿）
            best, best_area = q, a
    return best

# ===== 主循环 =====
def main():
    cam = camera.Camera(W, H, image.Format.FMT_RGB888, fps=30)
    disp = display.Display()
    cam.skip_frames(30)

    # 锁定曝光与白平衡 —— 阈值稳定的前提
    cam.exp_mode(camera.AeMode.Manual)
    cam.exposure(EXPOSURE)
    cam.gain(GAIN)
    cam.awb_mode(camera.AwbMode.Manual)
    cam.set_wb_gain(WB_GAIN)

    while not app.need_exit():
        img = cam.read()
        quad = detect_target(img)

        if quad is not None:
            Hm = build_homography(quad)

            # 画靶纸框
            for i in range(4):
                a_, b_ = quad[i], quad[(i + 1) % 4]
                img.draw_line(int(a_[0]), int(a_[1]),
                              int(b_[0]), int(b_[1]), image.COLOR_GREEN, 2)

            # 靶心
            c = project(Hm, CENTER_CM[0], CENTER_CM[1])
            if c:
                img.draw_cross(int(c[0]), int(c[1]), image.COLOR_RED, 12, 2)
                s = px_per_cm(Hm, CENTER_CM[0], CENTER_CM[1])
                img.draw_string(8, 8,
                    f"center=({c[0]:.1f}, {c[1]:.1f})  scale={s:.2f} px/cm",
                    image.COLOR_WHITE, 1.5)
        else:
            img.draw_string(8, 8, "target not found", image.COLOR_YELLOW, 1.5)

        disp.show(img)

    cam.close()

if __name__ == "__main__":
    main()
```

**这个 demo 的验证标准**：
- 四角框应紧贴黑胶带外沿，不跳内沿
- 靶心红十字应稳定居中于靶纸，随机摆放/倾斜时不跑偏
- `scale` 值应随距离单调变化（近大远小），且在 165cm 时约 6~7 px/cm

## 八、误差源与精度归属

| 误差源 | 典型量级 | 是不是瓶颈 | 改善手段 |
|---|---|---|---|
| **角点提取精度** | ±1~2 px | ⭐ **主要瓶颈** | 提高分辨率；`set_windowing` 换等效长焦；`lens_corr` 校正畸变 |
| 时序抖动 | ±3~5 px（滤波前） | 可消除 | One Euro Filter |
| 镜头畸变 | 边缘可达 ±5 px | 中等 | `img.lens_corr(strength)`；或让靶纸尽量靠画面中央 |
| H 求解数值误差 | < 0.1 px | 否 | 用 `getPerspectiveTransform`（4 点解析解） |
| 靶面尺度非线性 | — | 否 | 用局部 `px_per_cm` 而非全局平均 |
| 内外沿跳变 | 尺度突变 | 可检出 | 取最大面积候选 + 尺度跳变检测 |

**核心结论：靶心识别的精度几乎完全由"4 个角点定位得多准"决定。** 其余环节（排序、单应、投影、滤波）都是确定性或可优化的。所以调优的力气应该花在：
1. 提高靶纸在图像中的像素尺寸（分辨率 / windowing）
2. 保证黑框边缘清晰（曝光锁定、避免过曝和运动模糊）
3. 消除镜头畸变

## 九、标定与验证（只涉及靶心识别）

| # | 项目 | 方法 | 通过标准 |
