①「所有含时间的测试项，超时该项计 0 分」——每项都要按指标留 30% 余量设计，不要贴着 20s 做。

③ Di ≤ 2cm 为满分，每多 1cm 扣 1 分（不足 1cm 按 1cm 计）——精度就是扣分项，靶心锁定必须闭环到像素级。

2系统架构：双 MCU 解耦

题目强制「寻迹必须用 MSPM0」，但瞄准侧的视觉+云台算力需求远高于 M0。因此采用双控制器分工，唯一耦合点是串口。

为什么双 MCU：M0 只负责"把车开稳、把里程数准"；视觉与云台解算放在算力更强的 MCU 上，两边只靠一行串口协议通信。唯一耦合点越简单，联调越快——这是 4 天里能否腾出时间做画圆的关键。

3复刻的核心优势：赛前必须完成的"半成品包"

复刻 ≠ 从零。84 小时里没有时间做探索，只有时间做装配、标定、调参、写报告。以下 8 项必须在赛前完成，否则第 1 天就会崩。

代码与固件

  • CCS 工程骨架：MSPM0 的 PWM / 编码器 / 定时器 / 串口外设全部跑通并点灯验证
  • 循迹 PID 框架：权值归一化 + PID + 差速，参数空槽，赛场上只调不改结构
  • 视觉工程：靶纸识别（黑框 + 红圆 + 靶心）已在桌面跑通，输出靶心坐标
  • 云台 PID + 串口协议文档：帧头/长度/校验/字段全部定死

硬件与机械

  • 电源板已打样/洞洞板焊好：两路独立开关 + 双 LED 指示 + 5V/3.3V 降压
  • 云台加工件已试装：相机 - 激光笔 - 云台转轴必须同轴/共面标定过
  • 车体尺寸已卡：总轮廓 ≤ 25×15×25cm，云台举高后不超限
  • 备用件：激光笔 ×2、紫外感光纸 ×N、电机/驱动各 1 备

场地与标定流程

  • 喷绘布场地：100×100cm、黑线宽 1.8cm，白底哑光，除边线外无任何标记
  • A4 紫外感光纸靶：1.8cm 黑胶带外框 + 红点靶心 + 半径 2/4/6/8/10cm 红圆
  • 红外阈值标定流程文档：垂直移过引导线取 min/max 写数组
  • 相机-云台-激光标定流程：像素误差 → 云台角度的映射系数

提效工具

  • 无线/OLED 调参台：PID 六参数在屏上改，不必反复烧录（赛场 3 分钟整定一个环）
  • VOFA+ / 串口波形：编码器、灰度、图像误差实时可视化
  • 报告模板 + 图表规范：方案论证/理论分析/电路程序/测试数据四段式骨架

6三人分工与并行原则

电赛限 3 人。分工按"物理子系统"切，而不是按"软件/硬件"切——这样每人都有独立可验证的产出。

队员 A · 车体

  • 机械总装、电机/驱动/编码器
  • 红外标定 + 循迹 PID
  • 圈数计数、里程解算
  • 串口上报位置/进度
  • 产出：能稳定跑 5 圈的车

队员 B · 视觉+云台

  • 相机固定与标定
  • 靶心/激光点识别
  • 云台双环 PID
  • 动态补偿与画圆解算
  • 产出：能锁靶心、能画圆的云台

队员 C · 系统+报告

  • 电源板、走线、抗扰
  • 通信协议落地与调参台
  • 全场测评、数据记录、拍照留证
  • 报告撰写（每天 2h 滚动）
  • 产出：可复现的测试数据 + 报告
并行铁律：① 每天 08:00 / 20:00 各站会 10 分钟，只回答"昨晚卡在哪、今天要什么资源"；② 任何人不得长时间独自 debug 超过 2 小时，卡住就喊人；③ 每完成一个可跑状态立即提交/备份代码（带时间戳），第 4 天不再信任"凭记忆还原"。

7关键路径与风险

H2 → H12

① 机械总装（最长的单点）

云台举高、相机与激光笔的相对位姿一旦定死就难改。先画尺寸约束（25×15×25cm），再装。相机、激光笔必须与云台两轴同轴/共面，否则后面所有解算都要加一堆补偿系数。

H13 → H28

② 循迹稳定（10 分也是发挥部分的地基）

发挥部分全程要求"投影不脱线"，且画圆要靠里程/圈进度驱动。先求稳再求快：能 25s 稳定跑完比 18s 发抖更有价值。

H24 → H42

③ 静态打靶闭环（基本 40 分）

用图像误差做位置环，激光点当反馈。基本(2) 只有 2s，必须支持无目标时先扫描搜索；基本(3) 有 4s，可加一次粗校准。

H46 → H66

④ 动态补偿 + 同步画圆（决定上限）

小车运动时云台要反向补偿：用 IMU 角速度做前馈、用编码器里程算云台所需角度。画圆则把"圈进度 0~100%"映射成靶面 6cm 圆上的目标点，再反解云台角。这是本题的分数天花板。

高频风险与对策

  • 视觉在运动/复杂光照下抖动 → ROI 裁剪 + 候选轮廓筛选 + 数字滤波 + IMU 前馈；必要时 AI 检测兜底
  • 云台虚位/背隙 → 金属齿舵机或步进闭环；控制上留死区补偿
  • 电机启停导致 MCU 复位 → 电机/舵机独立供电 + 大电容 + 磁珠，逻辑地单点接地
  • 尺寸超限被拒测 → 结构设计阶段就卡死轮廓，留 5mm 余量
  • 超时归零 → 每项按指标的 70% 时间设计
  • 感光痕迹 20~60s 消失 → 打靶后立即拍照留证、贴标签记录

砍项决策线（保分优先级）

  • 8/1 12:00 未拿下动态瞄准(1) → 停止攻画圆，全力打磨静态瞄准精度与循迹稳定
  • 8/1 20:00 画圆未出闭合圆 → 降级为"固定半径近似"，优先保证 D₂ 与不脱线
  • 8/2 12:00 任何基本项不可复现 → 冻结所有发挥项，只保基本 50 分 + 报告
  • 任何时候：报告 不能 被牺牲，20 分是性价比最高的分
