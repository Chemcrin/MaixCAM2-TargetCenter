# 25Efork · 靶心识别与云台瞄准

一句话：用一台 MaixCAM2 找到 A4 靶纸的中心，再让双轴云台把激光指过去。

这是 2025 年全国大学生电子设计竞赛 E 题《简易自行瞄准装置》的视觉与控制部分。

## 要解决什么问题

题目要求在 1.65 米外瞄准靶纸中心。靶心是一个红色记号笔点，在这个距离下**不到 1 个像素**，
相机根本看不见。

所以换了个思路：不去找那个点，而是找**靶纸四周的黑胶带框**。
胶带围成一个矩形，矩形的两条对角线交点，就是靶心。

## 怎么做到的（四步）

1. **找框**：把画面缩小一半，按明暗自动分层（Otsu 阈值），找出像矩形的暗块，
   再让它们拟合成四边形。
2. **验框**：拿 A4 纸和胶带的真实尺寸去核对——胶带该多宽、暗带该比纸面暗多少、
   四条边够不够直。显示器边框、窗框、洞洞板这些"长得像"的东西，在这一步被刷掉。
3. **定中心**：取纸边矩形（胶带内沿）的四角，算两条对角线的交点。
   胶带贴得上下不等宽也不影响，因为用的是纸边，不是胶带外沿。
4. **云台瞄准**：算出靶心相对激光光斑差多少像素，换算成步进电机要走的脉冲数，
   两个轴各走一小步，下一帧再看、再修。

## 现在能做什么

- **识别**：640×480 灰度画面，锁定后只在上一帧附近找；跟丢了自己回全图重搜。
- **追踪**：上电看到靶纸就自动追，激光光斑稳定停在靶心附近（实测偏差 1 像素上下）。
- **自检**：屏幕上的 `TEST` 按钮让云台按左、右、上、下的顺序小幅往返，检查两个轴是否正常。
- **搜索**：`SEARCH` 按钮从当前位置向左扫 60°、再向右扫 60°，扫到靶纸就停下转入追踪。
- **标定**：开机自动做一次四步探针，量出"1 个像素要几个脉冲"和电机方向，不用手工填表。

## 需要什么硬件

| 部件 | 说明 |
|---|---|
| 主控 | MaixCAM2（MaixPy v4，板载 640×480 屏） |
| 云台 | 两台张大头 ZDT Emm42_V5.0 闭环步进，yaw 接 UART2 / ID 2，pitch 接 UART0 / ID 1 |
| 靶纸 | A4 白纸，四周贴 **18mm 宽**黑胶带 |
| 激光 | 激光笔与相机**同装云台**，光斑在画面里的位置基本固定 |

驱动器菜单要先设好：`P_Serial = UART_FUN`、`UartBaud = 115200`、`Checksum = 0x6B`、
两轴 `ID_Addr` 分别为 2 和 1、控制板与驱动器**共地**。

## 怎么跑

**方式一：整包运行（推荐）**

用 MaixVision 打开 `maixcam2_rect_center/` 目录，点「运行项目」。

**方式二：单文件运行**

`dist/main_single.py` 已经把全部代码打成一个文件。用 MaixVision 打开它，
点「运行当前文件」即可，适合现场快速试参数。

**单独标定云台**

`dist/calib_gimbal.py` 是独立的标定脚本：把靶纸完整放进画面，它会自动走四步探针，
在控制台打印 `PULSE_PER_PX` 和 `DIR_SIGN` 的建议值。

## 参数在哪

全部在 `maixcam2_rect_center/config.py`，现场只改这一个文件。

注意：文件末尾的 `apply_aim_profile("smooth")` 会在加载时覆盖六个增益/转速/限幅值，
直接改那六项的字面值可能不生效，改档位表或换档位名才行。

## 已知限制

- **胶带宽度必须与配置一致**：换胶带不改 `BLACK_FRAME_MM`，会稳定拒检。
- **正方形框不认**：长短边比小于 1.05 的框会被当成显示器/窗框拒掉。
- **靶纸要完整入画**：大半出画时没有完整框，宁可不报也不给错值。
- **没有绝对角度定位**：不发绝对坐标，只按"这一帧差多少"一步步补，所以每帧都要能看到靶纸。
- **低速不转**：驱动器低于约 15 rpm 只收指令不出力，代码把速度下限钉在 20 rpm。
- **激光位置是标定常量**：换距离或重装激光笔后要重标 `LASER_U_NOMINAL / LASER_V_NOMINAL`。
